# 🕒 Digital Clock

A stylish, glowing digital clock built with **HTML, CSS, and JavaScript**.  
It displays the current time, date, and a personalized greeting with a dynamic background that changes based on the time of day.

---

## 🚀 Live Demo
👉 [View the Clock](https://anuhari872-rgb.github.io/Digital-clock/)

---

## ✨ Features
- ⏰ Real-time digital clock (updates every second)
- 📅 Displays full date and weekday
- 🌅 Dynamic greeting (Good Morning / Afternoon / Evening)
- 🌈 Background changes with time of day
- 💡 Neon glowing effect for digits
- 📱 Responsive design for desktop and mobile

---

## 🛠 Tech Stack
- **HTML5** – Structure
- **CSS3** – Styling and glowing effects
- **JavaScript (ES6)** – Logic and real-time updates
